기존 핵심 기능 3건, UX 6건, 비기능 5건의 결함을 수정했다. 사용성 제안 2건과 SVG·설치/배포 보강 사항도 반영했다. 이전 보고서는 당시 재현 기록으로 유지한다.

분석 캐시 버전을 올리고 기존 원본으로 재분석한다. 경로별 최신 캐시만 표시하며, 대체 캐시 저장 성공 후 이전 사본을 정리해 원본 유실과 문항 수 중복 표시를 방지한다.

## 검증 결과

- JavaScript 자동 검사 113개 통과(회귀 검사 11개 포함), Python 4개 통과.
- 프로덕션 빌드 성공, Python 의존성 검사 통과.
- 합성 문항 분석: 100개 약 35ms, 300개 60ms, 600개 111ms. 600개 수정 전 약 2,424ms에서 개선. 관찰한 최대 타이머 지연 약 52ms. 로컬 Node/jsdom 측정으로 모바일 성능을 대표하지 않는다.
- 페이지 나눔 이후 마지막 선택지 보존, 12개 구역 숫자 정렬, 한국 시간 오전 날짜 회귀 검사 통과.
- 실패 주입 후 IndexedDB와 기본 템플릿 요청 모두 두 번째 시도 성공. 손상 CRC·과도한 선언 크기·실제 해제량 초과 차단 확인.
- 실제 브라우저 1280×720: 은행 2개, 시험지 4개에서 문항 수와 출제 버튼이 함께 보임. 은행 탭 방향키, 오류 연결, 파일 선택 버튼 Enter 확인.
- 실제 브라우저 390×844: 출력 패널 좌우 x=16~374로 화면 안에 표시. 하단 바 약 215px에서 120px로 축소, Escape 닫기 확인.
- 실제 두 탭: 최신 제목 저장 뒤 오래된 탭의 화면 조작으로 덮어쓰지 않음. 충돌 안내 후 최신 작업을 불러와 새 제목 복원 확인.
- 실제 다운로드: 시험지 4부, HWPX 결과 8개 생성. 바깥 ZIP과 안쪽 HWPX 8개의 CRC 및 XML 파싱 확인.

## 검증 범위의 한계

한컴오피스에서 출력물을 열고 인쇄한 결과, 실제 모바일 기기·모든 브라우저 조합, 정식 스크린리더 접근성 평가는 이번 재검증에 포함하지 않았다. 모바일 수동 검증은 390px 폭이며 320·768px 및 확대 조합은 추가 확인 대상이다. SVG 검사는 필터와 참조 제거를 확인한 것으로 전체 보안 감사를 뜻하지 않는다. 원격 CI·배포 결과는 로컬 검증과 별개다.
