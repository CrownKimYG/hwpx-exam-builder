# HWPX 템플릿 슬롯 출력

사용자가 업로드한 시험지 HWPX 템플릿에서 `#1`, `#2`, ... 형식의 문단을 문제 슬롯으로 인식합니다. 템플릿을 업로드하지 않으면 내장 빈 2단 템플릿의 `{{QUESTIONS}}` 위치 뒤에 문항을 연속 삽입합니다.

- `4 1 5 6`처럼 입력한 문항은 그 순서대로 슬롯 또는 연속 삽입 지점에 삽입합니다.
- `#해설` 문단은 해설 시작 표식으로 인식하고 최종 출력에서는 `해설`로 바꿉니다.
- 미주 숨기기 옵션을 선택하면 미주 글자와 수식 서식을 1pt·흰색으로 바꾸고 결과 검증에서도 적용 여부를 확인합니다.
- 문제은행 원본의 수식, 그림, 표, 미주 리소스를 유지합니다.
- 문제 본문과 해설을 붙여넣을 때 원본 글자 서식과 언어별 로컬 글꼴 참조를 유지합니다. 미주를 숨기거나 다시 표시할 때도 글꼴을 공통 기본 서식으로 바꾸지 않고 각 원본 서식의 표시 속성만 조정합니다.
- 삽입한 표와 본문 조건 글상자의 너비는 최종 템플릿의 입력 영역에 맞춥니다. 용지의 좌우·제본 여백, 단 수와 단 간격, 문단 여백, 개체 바깥 여백을 반영합니다.
- 표 내부에 삽입한 내용은 해당 셀의 안쪽 여백을 뺀 너비를 사용합니다. 표 열 비율과 병합 셀 경계를 유지하고, 사각형은 실제 가로 크기·변환 행렬·내부 글상자 너비를 함께 보정합니다.
- 작은 `풀이` 표식, 회전·그룹 도형, 글상자가 아닌 수학 도형과 템플릿 자체의 틀은 늘리지 않습니다. 너비가 서로 다른 다단에서는 가장 좁은 단을 기준으로 합니다.
- HWP 변환기가 음수 도형 치수를 unsigned 32비트 수로 내보낸 경우 최종 HWPX에서 signed 값으로 정규화합니다. 브라우저 미리보기는 이를 허용하지만 한컴오피스 뷰어는 해당 값에서 충돌할 수 있습니다.
- 여러 문제은행 파일을 합칠 때는 최종 본문·바탕쪽에서 실제 참조하는 글자·문단·번호·테두리 서식만 남긴 뒤 ID를 연속 번호로 다시 배치합니다. 원본별 서식표 전체를 누적하거나 정리 후 희소 ID를 남기면 Mac 한컴 뷰어의 내부 서식 배열이 손상되거나 표 테두리가 사라질 수 있습니다.
- 수능특강의 원문 줄바꿈과 수식 세로 배치는 유지합니다. 원문보다 훨씬 좁은 템플릿에서는 글자·수식이 겹치거나 상자 안에서 잘릴 수 있으므로 별도 재배치가 필요합니다. 자동 줄바꿈 재구성은 너비 보정에 포함하지 않습니다.
- 문제은행의 유형 표제 문단은 제외하고 실제 문제 블록부터 삽입합니다.
- 삽입한 최상위 문제 문단은 원래 문단 여백과 간격을 유지하면서 왼쪽 정렬 서식을 새로 만들어 적용합니다.
- 템플릿의 `CLICK_HERE` 누름틀 값은 문제 삽입 전에 적용합니다.
- 선택 문항 수가 템플릿 슬롯 수보다 많으면 생성을 중단합니다.
- 사용하지 않은 슬롯의 `#N` 표시는 빈 문단으로 정리합니다.
- 같은 번호의 슬롯이 중첩 표에 반복되면 가장 바깥쪽 슬롯 하나만 사용하고 중복 마커는 제거합니다.
- `마지막 페이지입니다.` 문단 뒤에 남은 복제 표지나 빈 문단은 출력에서 제외합니다.
- 누름틀 입력값은 최종 출력에서 일반 텍스트로 평탄화하여 안내 문자열이 다시 표시되지 않게 합니다.
- 다운로드 전에 슬롯 잔여 여부, 미주·정답·해설 수, 누름틀 미치환 문자열, BinData 참조를 검사합니다.
- 문제은행 전체가 아니라 선택 문항이 실제로 참조하는 BinData만 결과 파일에 유지합니다.

현재 가천대 파이널 템플릿은 `#1`~`#8`의 8개 문제 슬롯을 사용합니다. 실제 템플릿 및 문제은행 파일은 저장소에 커밋하지 않습니다.
