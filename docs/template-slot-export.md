# HWPX 템플릿 슬롯 출력

사용자가 업로드한 시험지 HWPX 템플릿에서 `#1`, `#2`, ... 형식의 문단을 문제 슬롯으로 인식합니다.

- 선택 문항은 선택 순서대로 슬롯에 삽입합니다.
- 문제은행 원본의 수식, 그림, 표, 미주 리소스를 유지합니다.
- 문제은행의 유형 표제 문단은 제외하고 실제 문제 블록부터 삽입합니다.
- 삽입한 최상위 문제 문단은 원래 문단 여백과 간격을 유지하면서 왼쪽 정렬 서식을 새로 만들어 적용합니다.
- 템플릿의 `CLICK_HERE` 누름틀 값은 문제 삽입 전에 적용합니다.
- 선택 문항 수가 템플릿 슬롯 수보다 많으면 생성을 중단합니다.
- 사용하지 않은 슬롯의 `#N` 표시는 빈 문단으로 정리합니다.
- 같은 번호의 슬롯이 중첩 표에 반복되면 가장 바깥쪽 슬롯 하나만 사용하고 중복 마커는 제거합니다.
- `마지막 페이지입니다.` 문단 뒤에 남은 복제 표지나 빈 문단은 출력에서 제외합니다.
- 누름틀 입력값은 최종 출력에서 일반 텍스트로 평탄화하여 안내 문자열이 다시 표시되지 않게 합니다.
- 다운로드 전에 슬롯 잔여 여부, 미주·정답·해설 수, 누름틀 미치환 문자열, BinData 참조를 검사합니다.
- 문제은행 전체가 아니라 선택 문항이 실제로 참조하는 BinData만 결과 파일에 유지합니다.

현재 가천대 파이널 템플릿은 `#1`~`#8`의 8개 문제 슬롯을 사용합니다. 실제 템플릿 및 문제은행 파일은 저장소에 커밋하지 않습니다.
