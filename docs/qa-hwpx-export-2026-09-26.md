# HWPX 생성 최적화 및 QA — 2026-09-26

기준 버전: `905c2d0`. 번호표 출제 UX와 최종 출력 검증은 유지한다.

## 최적화

- 변경되지 않은 ZIP 항목을 재사용하여 이미지·바이너리를 반복해서 해제·재압축하지 않는다. 수정한 XML은 기존처럼 새 항목으로 저장한다.
- HWPX 첫 번째 항목인 `mimetype`은 비압축 형식으로 다시 작성한다. ZIP CRC 및 해제 크기 검증은 유지한다.
- 문제지 전용 출력은 해설용 문제 영역 쪽수를 계산하지 않는다.
- 해설 포함 전용 출력은 사용하지 않는 문제지 출력 쪽수를 계산하지 않는다.
- 해설 위치가 정해진 양식은 불필요한 중간 문제지 생성·쪽수 계산을 생략한다.
- 양식의 해설 위치 확인은 각 부마다 반복하지 않고 다운로드 작업당 한 번 수행한다.
- 최종 파일은 기존처럼 문항·미주·렌더링·필요한 빈 페이지를 검증한다.
