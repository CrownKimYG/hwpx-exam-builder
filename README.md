# 시험지 제작실

국어·수학 HWP/HWPX 문제은행에서 문항을 선택하고, 과목별로 비동기 제작한 결과를
하나의 시험지로 이어 붙이기 위한 프로젝트입니다.

## 프로젝트 구조

- `app/`: 애플리케이션과 사용자 인터페이스
- `question_bank/`: 문제은행 파싱 및 관리
- `exam_builder/`: 문항 선택과 시험지 생성
- `hwpx_engine/`: HWPX 복사, 스타일, 리소스, 미주 처리
- `templates/`: 시험지 템플릿
- `tests/`: 자동화 테스트

## 설치

Python 가상환경을 만든 뒤 의존성을 설치합니다.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 로컬 실행

### Python 미리보기

```bash
streamlit run app/main.py
```

명령을 실행하면 기본 브라우저에서 로컬 개발 화면이 열립니다.

Python 3.10 이상이 필요합니다.

### GitHub Pages용 웹 화면

GitHub Pages에서는 Python 서버를 실행할 수 없으므로, 웹 화면은 브라우저에서
HWPX를 직접 읽고 HWP 5.0은 내부에서 HWPX로 변환하는 정적 앱으로 구성되어 있습니다. 선택한 파일은 서버로
전송하지 않고 현재 브라우저 메모리에서만 처리됩니다.

```bash
pnpm install
pnpm dev
```

배포용 파일은 `pnpm build`로 `web/dist/`에 생성됩니다.

## 여러 문제은행에서 시험지 생성

현재 브라우저 앱은 첨부된 `오답노트매크로.msr`와 같은 원리로 문항을 구분합니다.
모든 처리는 브라우저 메모리에서 이루어지며 원본 HWP/HWPX는 서버로 전송하지 않습니다.

1. 초기 화면에서 `폴더 선택`, `＋ 문제은행 추가` 또는 드래그 앤 드롭으로 원본을
   선택하고 문제은행 이름과 처리 방식을 정합니다. 한 문제은행에는 한 처리 방식만
   적용되며, 같은 원본의 HWP와 HWPX가 함께 있으면 HWPX를 우선합니다.
   HWP 5.0 파일은 `@rhwp/core`로 직접 읽고 HWPX로 내보낸 뒤 기존 파서에 전달하며,
   문제은행의 미주도 HWPX 미주로 보존합니다. 루트 본문에 있는 미주를 문항 시작점으로
   번호 매기고, 현재 문항부터 다음 문항 직전까지를 하나의 복사 블록으로 사용합니다.
   표나 글상자 내부의 미주는 문항 시작점으로 세지 않습니다.
2. `[수학]수특변형Z`는 파일명에서 과목·단원·권차를 읽습니다. 문제 윗줄의 난이도 표시는 빠른 출제를 위한
   보조 정보일 뿐이며, 문항 복사 범위나 시험지 생성 가능 여부에는 영향을 주지 않습니다.
3. 왼쪽에서 원본 페이지를 확인하고 시험지 카드에 `01-003 01-015 02-004`처럼
   `두 자리 파일코드-세 자리 문항번호` 형식만 입력합니다. `1-3` 같은 축약형은
   허용하지 않으며, 문항은 입력한 순서대로 배치합니다.
4. 하단 고정 바의 `생성·다운로드`를 누릅니다. 사용자 템플릿이 없으면 문제를
   한 쪽에 한 문항씩 배치하는 내장 기본 템플릿을 사용합니다.

입력란에 커서가 있어도 `Shift+↑/↓`로 파일을, `Shift+←/→`로 페이지를 이동할 수
있습니다. 화면의 맞춤/확대/축소 기능은 미리보기에만 영향을 주며 생성 문서는 바꾸지 않습니다.

### 수능특강 수학 처리 방식

`27약술 수능특강 수학1 _ 01 지수와 로그.hwp` 형식의 파일은 **`[수학] 수능특강`**으로
자동 선택합니다. HWP/HWPX만 처리하며 PDF는 제외합니다. 본문 미주를 문항 시작으로 읽고,
표지·분류 표제·빠른정답·원본 바탕쪽은 생성 시험지에 포함하지 않습니다.

약술법·연습문제는 `유제`, 기본은 `lv1`, 실력은 `lv2`, 심화는 `lv3`에 연결합니다.
원문 유형 5개, 소주제, EBS 출처코드는 별도 보존합니다. 이미 약술형인 자료이므로 문항 형식은
`원본`으로 고정하며, 원래 수식·미주·줄 배치를 유지합니다. 문제지에서는 미주 내용만 숨기고
문항 번호는 표시합니다. [인식 규칙과 검증 결과](docs/suteuk-short-essay-pattern-review.md)를 참고하세요.

### EBSi 국어 처리 방식

`[26001]_EBS 2027학년도 ... 국어영역 ..._(315).hwpx` 형식은 파일명으로
`EBSi 국어` 처리 방식을 자동 선택합니다. 가져오는 단계에서 각 `[문제]` 뒤의
`[정답/모범답안]`과 `[해설]`을 `[정답]`·`[해설]` 미주로 변환하며, 변환 이후에는
다른 문제은행과 동일한 `미주 기준` 복사·붙여넣기 규칙만 사용합니다. 같은 지문의 문항을
연속 선택하면 공통 지문은 시험지에 한 번만 들어가고, 문제지는 미주를 숨기며 해설지는
변환된 미주를 표시합니다.

파일에 적힌 `001~003` 범위보다 실제 XML에 있는 문항 경계를 우선하므로, 범위 표기와
실제 문항 수가 다른 파일도 다음 `[지문]`이 나올 때까지 같은 지문 묶음으로 처리합니다.

### 문제은행 캐시

처음 여는 폴더나 파일에는 문제은행 이름과 처리 방식을 지정합니다. 처리 방식은
`[수학]수특변형Z`, `[수학] 수능특강`, `[국어]EBS연계` 중 하나이며, 처리 방식이 다른 파일은 같은
문제은행에 섞을 수 없습니다. 문항을 찾지 못했거나 파일명에 적힌 문항 수와 분석 결과가
다르면 해당 파일만 오류로 표시하고 나머지 파일은 계속 사용할 수 있습니다.

앱은 문제은행 프로필과 파일별 문항 구간 분석을 IndexedDB에 저장합니다. 초기 화면의
문제은행 목록에서 저장된 분석 결과를 확인할 수 있으며, 문제은행을 누르면 상세 화면으로
이동합니다. 원본 사본과 출제용 데이터를 함께 저장하므로 다음 입장에는 파일 선택 없이
미리보기와 출제가 가능합니다. 이전 버전에서 분석만 저장한 은행은 최초 한 번 원본 연결이 필요합니다. 새 파일이나 크기·수정일이 달라진 파일만 다시 분석하며, 규칙 버전이
바뀌면 이전 분석 캐시는 사용하지 않습니다.

상세 화면 제목의 문제은행 이름은 클릭 후 Enter 또는 바깥 클릭으로 바꿀 수 있습니다.
목록에서는 캐시만 삭제할 수 있으며 원본 파일은 지워지지 않습니다. 캐시는 서버로 전송되지
않고 현재 브라우저와 주소에만 저장되므로 배포 페이지와 localhost 사이에는 공유되지 않습니다.

### 국어·수학 이어 만들기

국어와 수학 담당자는 각각 문항을 고른 뒤 `인계용 HWPX 저장`으로 작업 결과를 넘길 수
있습니다. 받은 사람은 초기 화면의 `이어 만들기`로 HWPX 또는 여러 인계 파일이 든 ZIP을
불러오고, 반대 과목 문제은행을 연결해 기존 시험지별 제목·순서·문항 수를 유지한 채 이어
붙입니다. 두 과목의 순서는 고정되지 않으며 기존 문항 다음 번호부터 자동으로 이어집니다.

최종 `생성·다운로드`에서는 앱 전용 인계 메타데이터를 제거하고 전체 미주를 다시 번호
매깁니다. 문제 영역이 홀수 쪽에서 끝나면 머리말·꼬리말·쪽번호가 없는 완전한 빈 페이지를
추가해 다음 영역이 짝수 쪽 뒤에서 시작하도록 합니다. 국어와 수학 문제 및 해설은 모두
1단으로 출력합니다.

### 빠른 출제 조건표

시험지 기본 이름, 시험지당 문항 수와 생성 부수를 입력한 뒤 조건표의 각 칸에 `#1 #2`처럼 배치할
문항 위치를 적습니다. `#1~~4`는 1번부터 4번까지, `All`은 전체 문항 위치를
뜻합니다.

빠른 출제로 여러 부를 만들면 기본 이름 뒤에 공백 없이 `01`, `02`처럼 번호가 붙습니다.

- 같은 문항 위치를 여러 조건 칸에 적으면 해당 조건들을 OR로 처리합니다.
- 마지막 `단원 랜덤` 행은 지정 난이도 안의 모든 문항을 같은 확률로 섞습니다.
- 마지막 `난이도 랜덤` 열은 지정 단원 안의 모든 문항을 같은 확률로 섞습니다.
- 오른쪽 아래 칸은 전체 단원·난이도에서 무작위로 선택합니다.
- 한 문제는 생성 묶음 전체에서 한 번만 사용하며, 조건을 만족하는 최대 시험지 수를 미리 계산합니다.
- 랜덤 시드가 같으면 같은 문제은행과 조건에서 같은 결과를 재현할 수 있습니다.

### 원본 블록 복사와 출력

앱은 객관식·주관식, 선택지 수, 정답 또는 해설 내용을 판별하지 않습니다. 선택한 문항의
텍스트·수식·표·그림·선택지·미주를 하나의 HWPX 블록으로 복사하고, 여러 문제은행을
합칠 때 필요한 스타일과 BinData 참조만 다시 연결합니다.

- `문제지 · 미주 숨김`: 원본 문항 블록을 복사하고 미주를 1pt·흰색으로 축약합니다.
- `해설지 · 원본 미주 표시`: 같은 문항 블록과 원본 미주를 그대로 유지합니다.
- `문제지 + 해설지`: 두 결과를 ZIP으로 내려받습니다.

서로 다른 문제은행에서 가져온 문항은 그림·수식·BinData·스타일 ID를 출력 문서에
병합하고 충돌하지 않도록 다시 연결합니다. 생성 결과는 HWPX 구조, 선택 문항 수와
미주 수, 리소스 연결을 검사한 뒤에만 다운로드합니다.

## 사용자 시험지 템플릿과 누름틀 입력

웹 화면에서 사용자가 시험지 HWPX 템플릿을 드래그 앤 드롭하거나 직접 선택할 수 있습니다.
템플릿의 `CLICK_HERE` 누름틀 필드명을 자동으로 읽어 입력칸을 생성하며,
같은 이름의 필드가 여러 곳에 있으면 한 번 입력한 값을 모든 위치에 적용합니다.

현재 샘플 템플릿에서 확인한 필드는 다음과 같습니다.

- `title`: 시험지 제목
- `time`: 시험 시간(분)
- `test_questions_count`: 총 문항 수

`test_questions_count`는 선택한 문항 수를 기본값으로 자동 연동하며 사용자가
필요하면 직접 수정할 수 있습니다. 입력한 값만 적용한 HWPX를 먼저 다운로드해
누름틀 반영 결과를 검증할 수도 있습니다.

사용자가 업로드한 템플릿 파일은 브라우저 메모리에서만 처리하며 저장소에
커밋하거나 서버로 업로드하지 않습니다.

공개용 기본 템플릿은 `web/public/templates/basic-math-exam.hwpx`에 있으며 실제
문제은행 내용은 포함하지 않습니다. 템플릿을 다시 만들 때는 다음 명령을
사용합니다.

```bash
python scripts/create_sample_template.py
```

웹 미리보기는 `@rhwp/core`의 WebAssembly 렌더러로 HWPX 문단·수식·표·그림을
페이지 SVG로 표시합니다. KaTeX 변환이나 원본 XML 코드는 화면에 노출하지
않습니다.

미리보기에서는 렌더링을 방해하는 수식 워터마크와 `zb` 표식만 화면상 정리합니다.
시험지 생성은 원본 내용을 해석하거나 바꾸지 않고, 새 템플릿에서 줄 위치를 다시 계산할
수 있도록 원본 줄 배치 캐시만 제거합니다. 문제지 출력에서는 미주 본문과 미주 번호
표식을 1pt 흰색으로 처리합니다.

원본 문제은행은 프로젝트에 복사하거나 저장하지 않습니다. 다른 문제은행
형식은 해당 파일의 XML 구조를 확인한 뒤 별도 파서를 추가해야 합니다.

암호화·배포용 HWP와 HWP 3.0은 브라우저 변환 대상이 아닙니다. 표·그림·수식 등
일부 고급 개체의 서식은 생성용 HWPX 내보내기에서 단순해질 수 있으므로, 생성한
시험지를 한컴오피스에서도 최종 확인하는 것을 권장합니다.

`python-hwpx`는 저장소에 소스를 복사하지 않고 Python 의존성으로 사용합니다.

## 자동 검사와 GitHub Pages 배포

- `.github/workflows/ci.yml`: Python 테스트, 브라우저 핵심 로직 테스트와 웹 빌드를 검사합니다.
- `.github/workflows/pages.yml`: CI가 성공한 `main` 커밋을 빌드해 GitHub
  Pages로 배포합니다.
- 배포 주소: <https://crownkimyg.github.io/hwpx-exam-builder/>

저장소의 **Settings → Pages → Build and deployment → Source**는
`GitHub Actions`로 설정합니다.

로컬에서 같은 검사를 실행하려면 다음 명령을 사용합니다.

```bash
pnpm test
pnpm build
pytest -q
```

### 서술형·채점표 문제은행

`서술형_117문항_미주해설_너비문구수정.hwpx`와 같은 파일은 **`[수학] 서술형·채점표`**로
자동 선택합니다. 각 문항 앞의 `단원 · 세부 유형 · 난이도 하/중/상 | 출처 / 원문 번호`를
읽어 파일 하나에서도 6개 단원으로 출제할 수 있습니다. 하·중·상은 출제표의 lv1·lv2·lv3에
연결하며, 원문의 난이도와 `순서06번` 같은 출처 표기도 별도로 보존합니다.

미주가 있는 본문 문단부터 다음 문항의 분류 표제 직전까지를 복사합니다. 분류 표제와 표지는
시험지에 넣지 않고 수식·그림·해설·채점표는 원본 블록을 사용합니다. 미주별 채점표 합계가
10점인지, 파일명에 적힌 문항 수와 실제 분석 결과가 일치하는지 검사합니다. 문항 형식은
`원본`으로 고정합니다. 문항 목록의 검색칸에서 코드·단원·유형·본문을 찾을 수 있습니다.

실제 원본과 추출한 목록은 공개 저장소·배포물에 포함하지 않습니다. 로컬 실행 후
`＋ 문제은행 추가`로 원본을 연결하면 사용할 수 있습니다.

### 여러 문제은행의 문항 수 지정

상단 **＋ 문제은행 추가**로 새 은행을 연결합니다. **현재 은행에 파일 추가**는 선택한 은행에
같은 처리 방식의 파일을 보탭니다. 폴더 선택으로 다른 은행을 열어도 기존 은행과 출제 목록은
유지됩니다. 빠른 출제의 **저장된 문제은행 추가**로 저장된 은행도 함께 열 수 있습니다.
이전 버전의 분석만 저장된 은행은 **현재 문제은행**에서 선택한 후 원본 파일이나 폴더를 한 번 연결하세요. 이후 자동 복원됩니다.

기본 출제 방식인 **문제은행별 문항 수**에서 각 은행의 시험지당 문항 수를 입력합니다.
예를 들어 A은행 5문항, B은행 3문항이면 매 시험지가 총 8문항으로 구성됩니다. 0문항인 은행은
출제에서 제외하며 합계는 1~100문항이어야 합니다. 문항은 은행 목록 순서대로 배치하고,
생성 묶음 전체와 이미 출제 목록에 있는 문항 사이에 중복이 없도록 선택합니다.
**단원·난이도 조건표**로 전환하면 기존 위치 지정 출제도 사용할 수 있습니다.

시험지 카드에는 은행별 문항 수를 표시합니다. **빠른 출제 → 접기**를 누르면 설정 영역의
높이도 줄어들어 출제 목록이 바로 아래로 올라오고 남은 공간을 사용합니다.

### 문제은행별 단원·난이도 조건표

빠른 출제에서 **문제은행별 단원·난이도 조건표**를 선택하면 각 은행에 독립된 표가 나타납니다.
은행별 문항 수는 그대로 적용되고 총 문항 수는 자동 합산됩니다. 각 표에는 해당 은행의
단원만 표시되며, 국어 EBS 은행은 강별 문항 위치를 지정합니다.

표의 `#1`, `#2`는 **해당 은행 안의 문항 위치**입니다. A은행 2문항, B은행 3문항이면
A은행 표에는 #1~#2, B은행 표에는 #1~#3을 지정합니다. 최종 시험지는 은행 목록 순서대로
이어 붙입니다. `All`은 해당 은행의 모든 위치, `#1~~3`은 해당 은행의 1~3번 위치입니다.
같은 위치를 여러 조건 칸에 넣으면 OR로 선택하며, 다른 은행의 문항으로 대체하지 않습니다.

0문항인 은행은 조건표에 이전 입력이 있어도 출제에서 제외합니다. 조건이 없는 위치나
지정 문항 수를 넘는 위치는 해당 은행 이름과 함께 오류로 표시합니다. 조건표와 문항 수만
출제를 위해 현재 세션에서 유지하며, 은행을 전환해도 다른 은행의 조건을 덮어쓰지 않습니다.

### 출제 작업 화면

은행 카드에서 **분석된 문항 수**, **원본 연결 상태**, **이번 시험지의 문항 수**를 각각 확인합니다.
**조건 설정**을 누르면 해당 은행의 탭으로 이동합니다. 0문항인 은행도 단원 표를 표시하되
입력을 비활성화하여 분석 실패와 출제 제외를 구분합니다. 서술형·채점표 은행은 하·중·상으로
표시하며 내부 lv1·lv2·lv3 조건과 연결합니다.

**이 은행 전체 랜덤**은 해당 은행의 기존 조건을 지우고 모든 위치를 랜덤으로 설정합니다.
다른 은행의 조건은 유지됩니다. 기본 제목·부수·추첨 시드는 **시험지 설정**에서 변경합니다.
파일 추가 대상과 저장된 은행 연결은 **연결된 문제은행 · 파일 관리**에서 선택합니다.

조건에 따라 시험지를 추가한 뒤 목록에서 문항 코드를 확인하거나 직접 고칠 수 있습니다.
삭제·비우기 직후에는 **되돌리기**로 이전 목록을 복구할 수 있습니다. 하단 **서식 · 추가 설정**에
템플릿·문항 형식·과목 제목·인계 저장을 모았으며, **HWPX 다운로드**로 최종 파일을 저장합니다.

### 재입장과 작업 복원

홈에서 은행 이름을 클릭하면 바로 출제할 수 있습니다. 여러 은행은 체크한 뒤 한 번에 엽니다.
은행 조합, 파일 코드, 은행별 문항 수와 조건표, 시험지 목록, 출력 옵션과 사용자 템플릿을
현재 브라우저에 보관하며 **이전 작업 이어가기**로 복원합니다.
저장된 파일은 등록 시점의 사본입니다. 디스크 변경 사항을 자동 감시하지 않으며,
수정한 파일을 다시 추가하면 같은 은행의 같은 경로를 기존 코드로 갱신합니다.
브라우저 사이트 데이터를 삭제하면 저장된 은행과 작업도 삭제됩니다.
인계 파일을 합치는 작업은 기존 **작업 저장** 기능으로 보관하며, 일반 출제 작업의 자동 저장과 구분합니다.

### 출제 조건 템플릿

출제 구성의 **저장 · 관리**에서 현재 설정을 이름으로 저장합니다. 은행 순서와 문항 수,
문항 번호별 단원·난이도 조건(`1`, `2-4`, `All` 등), 출제 방식, 시험지 이름·부수가 함께 저장됩니다.
목록에서 템플릿을 선택하고 **적용**하면 설정이 복원됩니다. 필요한 저장 은행은 자동으로 추가하고,
템플릿 밖의 열린 은행은 0문항으로 설정합니다. 기존 시험지 목록과 현재 추첨 시드는 유지됩니다.
은행 삭제·처리 방식 변경·조건에 사용한 단원 누락 시에는 오류를 표시합니다.
새 이름으로 저장, 선택 템플릿 덮어쓰기와 삭제를 지원하며 이 브라우저에 보관합니다.
HWPX 출력 서식 템플릿과 별개 기능이며, 인계 작업 중에는 적용할 수 없습니다.

### 조건을 바꿔도 이전 출제 문항 제외

**중복 관리 · 출제 이력**의 ‘이전에 출제한 문항 제외’는 기본으로 켜져 있습니다.
자동으로 시험지를 추가할 때 사용 문항을 브라우저에 기록하며, 목록을 지우거나 템플릿·문항 수·난이도를
바꾸고 다시 입장해도 기록된 문항을 추첨 후보에서 제외합니다. 직접 입력·수정한 문항은 출력 시 기록하고,
이전 시험지와 중복되는 직접 입력은 제외 설정이 켜져 있으면 차단합니다. 같은 시험지의 재다운로드는 가능합니다.
미사용 문항이 부족하면 출제를 중단합니다. 새 출제 주기를 시작하려면 이력을 초기화할 수 있습니다.
식별 기준은 은행 ID + 파일 상대 경로 + 원문 문항 번호입니다. 다른 은행에 복제한 문제의 내용 유사도 검사는
하지 않으며 파일 경로나 문항 순서가 바뀌면 동일 문항 추적을 보장하지 않습니다. 기능 추가 전의 출제 기록은
자동 복원되지 않습니다. 이력은 현재 브라우저에 저장되며 사이트 데이터를 지우면 함께 삭제됩니다.

### 전체 번호에서 혼합 배치

출제 방식에서 **전체 번호에서 혼합 배치**를 선택합니다. 은행별 문항 수는 기존 입력란에서 지정하고,
배치 조건마다 은행·단원·난이도, 문항 수, 최종 시험지의 등장 번호를 지정합니다.
은행·단원·난이도의 ‘전체’는 제한 없음이며, 단원을 지정하려면 은행을 먼저 선택합니다.
각 조건 행은 별도의 문항 묶음입니다. 조건별 문항 수 합계는 은행별 합계와 같아야 하며,
겹치는 조건을 만족하는 문항도 한 행에만 배정되어 중복 집계되지 않습니다.

예: 총 8문항을 하 2문항(1-4번), 중 4문항(2-7번), 상 2문항(5-8번)으로 설정할 수 있습니다.
은행별 등장 번호 범위도 별도로 제한할 수 있으며, 번호 하나와 문항 수 1을 지정하면 해당 조건을 고정합니다.
범위는 `1-9`, `1~9`, `#1~~9`, 쉼표로 구분한 번호 또는 `All`을 받습니다. 빈 범위는 전체입니다.
은행 순서대로 붙이지 않고 모든 조건과 사용 이력을 함께 만족하는 조합을 무작위로 찾습니다.
난이도 ‘하/중/상’은 은행의 lv1/lv2/lv3에 대응하며, 유제·미분류는 별도 선택합니다.

혼합 조건은 출제 템플릿과 작업 이어가기에 저장됩니다. 기존 은행별 템플릿은 기존 방식대로 적용됩니다.
시험지 목록의 **번호별 은행 · 난이도**에서 최종 배치를 확인할 수 있습니다.
혼합 출제는 최대 부수 추정 대신 요청한 부수의 구성 가능 여부를 검사합니다.
한 번에 총 1,000문항까지 지원하며 탐색 시간·노드 한도에 도달하면 명시적으로 중단하고 조건을 완화하지 않습니다.
